## このリリースの変更点

- インストーラでの配布を開始しました。これまでのフォルダを展開して bat ファイルから
  起動する方法は不要になります。
- 自動更新に対応しました。新しい版が出ると裏で取得し、次に Glance を終了したときに
  適用されます。操作は必要ありません。
- インストーラのサイズを 346MB から 117MB へ減らしました。
- 初回起動時の AI モデルのダウンロードについて、進み具合を音声でお知らせするように
  なりました。通信が止まったときや、やり直しになったときもお伝えします。
- ダウンロードしたファイルが壊れていないかを確認するようになりました。途中で通信が
  切れた場合は自動でやり直します。
