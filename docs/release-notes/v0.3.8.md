## このリリースの変更点

- Glance の画面を最前面に固定しないようにしました。ほかのアプリに切り替えると、そのアプリが手前に出ます。固定したいときは、設定の「表示」で選べます。
- Windows の拡大鏡のレンズモードで、Glance の画面が透明になって見えなくなるのを直しました。
- NVDA が動いているときは、設定を変えなくても読み上げを NVDA に任せるようにしました。Glance の声で読ませたいときは、設定の「読み上げ方法」で選べます。
- 説明を選んでいるときは、Alt キーなしの上下矢印でも、ひとつずつ前後の説明に移れるようにしました。
- AI の準備中は、1分ごとに経過をお知らせするようにしました。
- 設定に「省電力モード」を加えました。AI が使う CPU を半分にして、ファンの音を抑えます。説明が出るまでの時間は長くなります。
