# プロジェクト「Glance」要件定義書
**Version:** 1.0
**Date:** 2026/01/17
**Project Code:** Glance

## 1. プロジェクト概要
### 1.1 ビジョン (Vision)
**"Glance" (一瞥)**
視覚障害者がPC操作において、晴眼者が無意識に行っている「一瞥（パッと見て全体を把握する）」という行為をテクノロジーで再現する。
究極的には、Webブラウジング、アプリ操作、開発作業など、PC上のあらゆるタスクにおいて、視覚による情報取得速度の格差をゼロにすることを目指す。

### 1.2 今回のミッション (Phase 1 Scope)
就労継続における最大の障壁であり、既存のスクリーンリーダーでは対応不可能な**「オンライン会議における画面共有資料のリアルタイム把握」**を実現する。

## 2. ターゲットユーザー & ユースケース
* **ユーザー:** 企業に勤務する視覚障害者（全盲・ロービジョン）。
* **環境:** セキュリティ要件が厳しく、管理者権限を持たない業務用PC。
* **課題:** 会議で「画面を見てください」と言われた瞬間に情報が途絶える。

## 3. システム構成・技術要件
### 3.1 アプリケーション形態
* **プラットフォーム:** ブラウザ拡張機能 (Google Chrome / Microsoft Edge)
* **規格:** Manifest V3

### 3.2 AI・セキュリティ要件 (最重要)
* **処理方式:** ブラウザ内ローカル実行 (On-Device AI)
* **使用技術:** WebGPU + Transformers.js + Florence-2 (または同等の軽量VLM)
* **通信制約:** AI解析に伴う画像データの外部サーバー送信は**一切行わない**。
* **コスト:** 恒久的に無料 (API課金なし)。

## 4. 機能要件 (Functional Requirements)
| ID | 機能名 | 内容 |
|:---|:---|:---|
| **F-01** | 画面キャプチャ | `getDisplayMedia` APIを使用し、ユーザーが指定したウィンドウ（Zoom/Teams等）の映像を取得する。 |
| **F-02** | オンデマンド解析 | 常時監視ではなく、ユーザーのトリガー（ショートカットキー等）時のみ画像を解析する（スナップショット方式）。 |
| **F-03** | 画像理解・テキスト化 | 取得した画像に対し、概要（何の話か）と詳細（数値・結論）をテキスト化する。 |
| **F-04** | アクセシブルUI | 解析結果をスクリーンリーダーが即座に読み上げるUIを提供する (`aria-live`対応)。 |
| **F-05** | クリップボードコピー | 解析結果をワンタッチでコピー可能にする。 |

## 5. 非機能要件 (Non-Functional Requirements)
* **レスポンス:** 解析開始から結果提示まで、標準的なビジネスPCで10秒以内。
* **ユーザビリティ:** インストールから日常操作まで、マウス不要のキーボード操作のみで完結すること。
* **互換性:** 主要な会議ツール（Zoom, Microsoft Teams, Google Meet）のアプリ版およびブラウザ版に対応。
