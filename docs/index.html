Glance

画面の情報を外に出すことなく、いま映っているものを AI が日本語で読み上げます。無料です。

ダウンロード

インストールの前に、このページの下にある インストール手順と初回起動についてに 目を通しておくことをおすすめします。

Glance をダウンロード（Windows 用、zip ファイル、約 115MB）

Glance について

Glance は Windows 用の無料アプリです。スクリーンリーダーでは読めない画像・図・ グラフ・レイアウトを、ホットキー一つで日本語の説明にします。

画像がパソコンの外に送られることはありません。 AI はパソコンの中だけで動きます。インターネットが必要なのは、初回起動時に AI 本体をダウンロードするときだけです。利用登録やアカウント作成も要りません。

動作条件

  • OS: Windows 10 または Windows 11（64ビット）
  • メモリ: 8GB 以上
  • 空き容量: 約 3GB（アプリ本体と AI モデルの合計）
  • インターネット: 初回起動時のみ必要（AI モデルのダウンロードのため）

グラフィックス機能があれば自動的に使用して高速化します。無い場合も CPU で動作します。

インストール手順

ダウンロードのリンクを押すと、最新版のインストーラを入れた zip ファイル Glance-Setup.zip のダウンロードがすぐに始まります。 GitHub のアカウントやログインは必要ありません。

zip を使えない場合は、 インストーラを直接ダウンロード（Glance-Setup.exe） することもできます。ただし、ブラウザやセキュリティソフトの設定によっては、 ダウンロードが途中で止まることがあります。

  1. 上のリンクから Glance-Setup.zip をダウンロードします。
  2. ダウンロードした zip ファイルを選んでアプリケーションキー（または右クリック）を押し、 「すべて展開」を選びます。続いて「展開」ボタンを押します。
  3. 展開してできたフォルダーの中の Glance-Setup.exe を実行します。
  4. 「WindowsによってPCが保護されました」という画面が出た場合、 次の操作で進めてください。

    これは、開発者証明書を購入していない個人開発のアプリすべてに出る警告です。 Glance に問題があるという意味ではありません。

    1. 「詳細情報」というリンクを押します（スクリーンリーダーではリンクとして読まれます）。
    2. 表示された「実行」ボタンを押します。
  5. インストールが終わると、デスクトップとスタートメニューに Glance が追加されます。

初回起動について

初めて起動したときだけ、AI モデル（約 1.9GB）をダウンロードします。 始める前に「今すぐダウンロードするか」を確認しますので、 都合が悪いときは「後でダウンロードする」を選んでください。 次に起動したときに、もう一度お聞きします。

回線の速さによっては 5 分から 30 分ほどかかります。 進み具合は 25% ごとに音声でお知らせします。 その間、ほかの作業をしていてかまいません。 通信が止まったときや、やり直しになったときもお伝えします。

2 回目以降の起動では、このダウンロードは発生しません。

使い方

インストール後は常駐します。どのアプリを使っているときでも、次のキーが使えます。

  • Ctrl + Shift + G … いまの画面を説明する
  • Ctrl + Shift + F … 何の画面かだけを、ひとことで伝える（いちばん早く言い終わる）
  • Ctrl + Shift + D … 直前に説明した画面を、さらに詳しく説明する
  • Ctrl + Shift + Q … 直前の画面について質問する
  • Ctrl + Shift + P … 画面を先に取り込んでおく（読み上げはしない）

Ctrl + Shift + P は、これから説明させたい画面を先に取り込んでおく機能です。 取り込みだけ済ませておくと、Ctrl + Shift + D や Ctrl + Shift + Q の応答が速くなります。

読み上げを途中で止める

Esc キーを押すと、読み上げと説明の作成をすぐに止めます。 ほかのアプリを使っている最中でも止められます。 Esc キーで止められるのは Glance がしゃべっている間だけで、 それ以外のときは、いま使っているアプリにふだんどおり届きます。

説明書

Glance の画面で F1 キーを押すと、説明書が開きます。 ウェブでも読めます（テキストファイル）。

更新について

新しい版が出ると自動で更新されます。操作は必要ありません。

うまく動かないときは

  • キーを押しても何も言わない … 他のアプリが同じキーを使っている可能性があります。 一度 Glance を終了して起動し直してください。
  • 起動が遅い … 初回はモデルの読み込みに 30 秒から数分かかります。
  • セキュリティソフトに止められた … AI の実行ファイルが誤検知されることがあります。 Glance のインストール先を除外設定に追加してください。

解決しない場合は、Glance の画面の右上にある「ご意見を送る」ボタンから知らせてください。 GitHub のアカウントは要りません。 Glance が起動しないときは、 ご意見・不具合の送信フォーム から送れます。

プライバシーについて

Glance が撮影した画面は、そのパソコンの中だけで処理されます。 外部のサーバーへ送信することはありません。 通信が発生するのは次の 2 つの場合だけです。

  • 初回起動時に、AI モデルを配布元からダウンロードするとき
  • 新しい版が出ていないかを確認し、更新を取得するとき
