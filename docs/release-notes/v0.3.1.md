## このリリースの変更点

- 読み上げを途中で止められるようにしました。Glance がしゃべっている間に Esc キーを
  押すと、読み上げと説明の作成をすぐに止めます。ほかのアプリを使っている最中でも
  止められます。Glance がしゃべっていないときは、Esc キーはふだんどおり、いま
  使っているアプリに届きます。
- 初めて起動したとき、AI モデル（約1.9GB）のダウンロードを始める前に確認するように
  しました。「後でダウンロードする」を選ぶと Glance は終了し、次に起動したときに
  もう一度お聞きします。
- Glance の画面を閉じた後にもう一度起動すると、画面が出るようにしました。
  これまでは常駐したまま何も起きませんでした。
- 説明書を用意しました。Glance の画面で F1 キーを押すか、画面上部の「説明書」
  ボタンを押すと開きます。通知領域の Glance のメニューからも開けます。
  ウェブでも読めます: https://panpanpanda7.github.io/Glance/manual.txt
