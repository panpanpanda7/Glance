Glance 説明書

Esc キーで元の画面に戻ります。


1. 基本の使い方

どのアプリを使っているときでも、次のキーが使えます。

Ctrl + Shift + G   いまの画面を説明します
Ctrl + Shift + F   何の画面かだけを、ひとことで伝えます
Ctrl + Shift + D   直前の画面を、さらに詳しく説明します
Ctrl + Shift + Q   直前の画面について質問します
Ctrl + Shift + P   画面を取り込むだけで、説明はしません

Ctrl + Shift + D と Ctrl + Shift + Q は、直前に Ctrl + Shift + G、Ctrl + Shift + F、Ctrl + Shift + P のどれかで取り込んだ画面について答えます。
先に Ctrl + Shift + P で取り込んでおくと、応答が速くなります。

質問は、入力欄に書いて Enter キーで送ります。Esc キーで取り消します。


2. 読み上げを止める

Esc キーで、読み上げと説明の作成を止めます。ほかのアプリを使っている最中でも止められます。
Glance が読み上げていないときの Esc キーは、いま使っているアプリに届きます。


3. 結果の画面

Alt + Tab キーで Glance の画面に切り替えると、これまでの説明を聞き直せます。

Ctrl + End     いちばん新しい説明
Ctrl + Home    いちばん古い説明
Alt + 上矢印   ひとつ前の説明
Alt + 下矢印   ひとつ後の説明
Enter          選んでいる説明をもう一度読む
F1             この説明書


4. 設定

画面右上の「設定」ボタンで開きます。

読み上げ方法: スクリーンリーダーに読ませたいときは「読み上げない（スクリーンリーダーに任せる）」を選びます。
音声、読み上げ速度: 声と速さを変えられます。
ホットキー: ほかのアプリとキーが重なるときに変えます。
画像解像度: 既定の 896px のままをおすすめします。


5. 終了

画面を閉じても Glance は常駐し、キーは使えます。
終了するには、通知領域（Windows キー + B）の Glance のメニューから「終了」を選びます。
閉じた画面は、Glance をもう一度起動すると出ます。


6. 初めて起動したとき

AI モデル（約 1.9GB）をダウンロードするか確認します。5分から30分ほどかかり、進み具合は25%ごとに音声でお知らせします。その間、ほかの作業をしていてかまいません。
「後でダウンロードする」を選ぶと終了し、次の起動時にもう一度お聞きします。


7. 困ったとき

キーを押しても反応しない: ほかのアプリが同じキーを使っている可能性があります。設定でキーを変えてください。
起動が遅い: AI の読み込みに数分かかることがあります。起動完了の音を待ってください。
セキュリティソフトに止められた: Glance のインストール先を除外設定に追加してください。
説明が実際と違う: AI は間違えることがあります。大事な内容はほかの方法でも確かめてください。


8. そのほか

画面の画像はパソコンの中だけで処理し、外部に送りません。
新しい版が出ると自動で更新されます。
不具合やご意見は、Glance の画面の右上にある「ご意見を送る」ボタンから送れます。タスクトレイのメニューからも開けます。
