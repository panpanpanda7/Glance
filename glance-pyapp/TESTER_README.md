# Glance テスター向け セットアップガイド（Windows）

視覚障害者向けPC画面読み上げアプリ **Glance** のテスト環境を構築する手順です。

---

## 必要なもの

| ツール | バージョン | ダウンロード先 |
|--------|-----------|----------------|
| Git | 最新版 | https://git-scm.com/download/win |
| Python | 3.11 以上 | https://www.python.org/downloads/ |
| Node.js | LTS 版（20 以上） | https://nodejs.org/ |

> **Python インストール時の注意**  
> インストーラーの最初の画面で **「Add Python to PATH」にチェック** を入れてください。

---

## 推奨スペック

| 項目 | 最低 | 推奨 |
|------|------|------|
| RAM | 8 GB | 16 GB |
| ストレージ空き容量 | 10 GB | 20 GB（モデル複数使用時） |
| OS | Windows 10 64-bit | Windows 11 |

---

## 初回セットアップ（1回だけ）

### 1. リポジトリをクローン

```cmd
git clone https://github.com/panpanpanda7/Glance.git
cd Glance
```

### 2. セットアップスクリプトを実行

エクスプローラーで `Glance\glance-pyapp\` フォルダを開き、  
**`setup-first-time.bat` をダブルクリック**してください。

スクリプトが自動的に以下を行います：

1. Git / Python / Node.js のインストール確認
2. Python 仮想環境の作成
3. Python 依存関係のインストール（PyTorch 等、数分かかります）
4. Node.js 依存関係のインストール
5. AI モデルファイルの自動ダウンロード（数 GB、時間がかかります）

完了後、アプリを起動するか確認されます。

---

## 2回目以降の起動方法

**`update-and-run.bat` をダブルクリック**するだけです。

以下を自動で行います：

```
git pull → 依存関係の差分更新（変更があれば） → Glance 起動
```

> 依存関係に変更がなければインストールはスキップされるため、  
> 通常は数秒で起動まで進みます。

### 高速モード（お使いのPCで説明が遅すぎる場合）

**`update-and-run-light.bat` をダブルクリック**すると、軽量なAIモデル
（Qwen3.5-2B）で起動します。使い方・ショートカットは通常版と同じです。

- **速さ**: CPUのみのPCで説明の開始が約3倍速くなります（実測: 約29秒→約11秒）
- **精度**: 読み取りの細かさは通常版より一段下がります（画面の種類や要点は読めますが、
  細かい数値や固有名詞を読み間違えることがあります）
- 初回は軽量モデル（約1.9GB）を自動ダウンロードします
- 通常版と高速版は**同時には起動できません**（どちらか片方だけ起動してください）

> どちらを常用するかは、お使いのPCでの体感で選んでください。
> 通常版で十分速ければ通常版（精度優先）がおすすめです。

## 初回起動時の注意

- アプリ起動後、**AIモデルのロードに 30 秒〜数分かかります**。  
  起動音が鳴るまでしばらくお待ちください。
- システムトレイ（画面右下の通知領域）にアイコンが表示されます。
- コマンドプロンプトのウィンドウは起動後に閉じても構いません。

## ショートカットキー

どのアプリを使っていても効くキーです。

| キー | 動作 |
|------|------|
| `Ctrl + Shift + G` | 今の画面を読み取って**要約**する |
| `Ctrl + Shift + P` | 今の画面を**記録するだけ**（説明はしない） |
| `Ctrl + Shift + D` | 記録した画面の**全体を詳細に説明する** |
| `Ctrl + Shift + Q` | 記録した画面について**質問する** |

### 3つの機能の違い

- **要約（G）** … 今の画面が何で、どんな状態かを短くまとめて伝えます。まずこれを使ってください。
- **詳細（D）** … 一部を深掘りするのではなく、**画面全体をひととおり詳しく**説明します。
  現在の状態、主な操作、警告や強調表示まで、要約では省いた部分を含めて伝えます。
- **質問（Q）** … 画面について知りたいことを自分で入力して尋ねます。
  「この表の合計は」のように、特定の箇所を深く知りたいときはこちらです。

### どの画面について説明されるか

`Ctrl+Shift+D`（詳細）と `Ctrl+Shift+Q`（質問）は、**撮り直しません**。
直前に `Ctrl+Shift+G` か `Ctrl+Shift+P` で読み取った画面について答えます。
説明の冒頭で「14時5分30秒の画面について」と対象の時刻をお伝えします。

別の画面に切り替えてから詳細を聞きたいときは、先に `Ctrl+Shift+P` で
その画面を記録してください。`Ctrl+Shift+P` は説明を読み上げないかわりに、
裏で準備を済ませるので、**続けて押す D や Q の反応が速くなります**
（実測で初動が半分以下）。

### ホットキーを変更したいとき

お使いのスクリーンリーダーや他のアプリとキーが重なる場合は、
Glance の画面の右上にある **「設定」ボタン**（Tab キーでも移動できます）を押すと、
設定画面に切り替わります。ホットキーはその中で変更できます。
`Esc` キーか「戻る」ボタンで、認識結果の画面に戻ります。
登録できなかったキーは、その場で読み上げてお知らせします。

## 設定画面

Glance の画面の右上に **「設定」ボタン** があります。
押すと画面全体が設定画面に切り替わります（認識結果の画面に重ねて出したりはしません）。
読み上げ・ホットキー・画像解像度・起動ログをここでまとめて設定できます。

- 戻るとき … `Esc` キー、または左上の「戻る」ボタン
- 設定画面を開いたまま `Ctrl+Shift+G` などを押した場合は、
  自動で認識結果の画面に戻って結果を表示します

---

## 履歴を読み返す（Glance の画面を開いているとき）

| キー | 動作 |
|------|------|
| `Ctrl + Home` | 履歴のいちばん最初へ |
| `Ctrl + End` | いちばん新しい説明へ |
| `Alt + ↑` / `Alt + ↓` | 1件ずつ移動（「14時5分30秒」のように時刻を先に読み上げてから内容を読み上げるので、結果の境目が分かります） |
| `Enter` | 選択中の説明をもう一度読み上げる |
| `Esc` | 読み上げを止める |

---

## 読み上げの設定

右上の **「設定」ボタン** を押すと設定画面に切り替わり、その中に読み上げの設定があります
（`Esc` キーで認識結果の画面に戻ります）。

- **読み上げ方法**
  - `Glanceが読み上げる（推奨）` … Glance 自身が喋ります
  - `Glanceが読み上げる（OS標準の音声合成）` … 上でうまく喋らない場合にお試しください
  - `読み上げない（スクリーンリーダーに任せる）` … PC-Talker などご自身のリーダーの声で聞きたい場合
- **音声 / 読み上げ速度** … お好みに合わせて変更できます
- **読み上げをテスト** … 音が出るかをその場で確認できます。
  日本語の音声がパソコンに入っていない場合は、その旨をお知らせします

## トラブルシューティング

### `Python が見つかりません` と表示される
→ Python を再インストールし、**「Add Python to PATH」** にチェックを入れてください。

### モデルのダウンロードが失敗する
→ `python-backend\config.yaml` を開き、`activeModel` のモデルの `download_url` を確認して、  
　手動でダウンロードし `python-backend\models\gguf\` に配置してください。

### アプリ起動後に何も反応しない
→ コマンドプロンプトのエラーメッセージを開発者に共有してください。

### 読み上げの声が聞こえない
1. 右上の「設定」ボタンを押し、設定画面の **「読み上げをテスト」** を押してください。
2. 何も聞こえない場合は、**読み上げ方法**を
   `Glanceが読み上げる（OS標準の音声合成）` に変えてもう一度テストしてください。
3. 「日本語の音声が見つかりません」と表示された場合は、Windows の
   **設定 → 時刻と言語 → 音声認識** から日本語の音声を追加してください。
4. PC-Talker などをお使いで、ご自身のリーダーの声で聞きたい場合は
   読み上げ方法を `読み上げない（スクリーンリーダーに任せる）` にしてください。

テストの結果（検出された音声の数と名前が表示されます）をお知らせいただけると、
原因の切り分けができます。

### 「ポート 5001 は既に使用されています」と表示される
前回の Glance がまだ終了していない状態です。
`update-and-run.bat` から起動し直すと、残ったプロセスを止めてから起動します。

### 説明が途中で止まる / 同じことを繰り返す
説明の最後に「（説明が長くなったため、ここまでで止めました）」
「（同じ説明の繰り返しが始まったため、ここで止めました）」とお伝えします。
このメッセージが出た画面を教えていただけると調整できます。

### 説明している画面が、実際に見えている画面と違う
- `Ctrl+Shift+D` と `Ctrl+Shift+Q` は撮り直さない仕様です。
  説明の冒頭の時刻が、意図した画面のものかご確認ください。
- 画面が複数ある場合は、**マウスカーソルのある画面**を読み取ります。
- それでも食い違う場合は、そのときの状況を教えてください。

### `npm start` でエラーが出る
→ `glance-pyapp\electron\` フォルダで手動実行して確認してください：
```cmd
npm install
npm start -- --dev
```

## フォルダ構成（参考）

```
Glance\
└── glance-pyapp\
    ├── setup-first-time.bat   ← 初回セットアップ（1回だけ実行）
    ├── update-and-run.bat     ← 毎回の起動はこちら
    ├── TESTER_README.md       ← このファイル
    ├── python-backend\
    │   ├── app.py             （バックエンドサーバー）
    │   ├── config.yaml        （モデル設定）
    │   ├── requirements.txt   （Python 依存関係）
    │   └── models\gguf\       ← モデルファイルをここに配置
    └── electron\
        ├── main.js            （Electron メインプロセス）
        └── package.json       （Node.js 依存関係）
```
